How can I take useful notes for Summarize Spoken Text?

Learn the reasoning through one worked example, then return to the original LizOn class for a complete demonstration.

Where students struggle

Trying to transcribe everything can distract from the lecture's main relationships. Start with the exact task instructions and understand what information is needed.

Try an original example

Original mini-lecture: “Coastal wetlands reduce flood impacts, support wildlife and store carbon, but urban expansion threatens them.”

Show the suggested reasoning

Organize notes by topic, functions and challenge. A summary should connect wetlands with flood protection, biodiversity and storage, while mentioning development pressure only if relevant.

A practical review routine

Attempt the task independently, compare your answer with the explanation, then record one specific mistake to address. Repeat the task type using a different passage or recording. Focus on comprehension and accuracy rather than shortcuts or an assumed score improvement.
